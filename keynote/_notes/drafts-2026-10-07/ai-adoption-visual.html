Nearly half of our pull requests now carry an agent’s mark

The slide’s own content sits here. The visual is 560 × 300, bottom right.
<none yet> DRAFT, 2026-10-07. Candidate A, the recommended one. Every word on the visual is draft wording.

What it shows. Grey: pull requests opened by people in each quarter (150, 147, 94, 67, 144, 167, 171). Teal: the ones that carry an AI agent's mark (0, 1, 5, 3, 9, 68, 80). A mark is any of: the team's attribution line in the description ("This PR was drafted by … using …"), a tool's own footer ("Generated with Claude Code"), or a commit co-authored by Claude or Copilot. A Copilot review, or a Copilot suggestion accepted in the browser, does not count as a mark here.

The true statement. Since April, 148 of 338 pull requests (44%) carry an AI agent's mark. In the same months of 2025 it was 6 of 241 (2.5%). The step is in April 2026: January to March 2026 was 9 of 144.
• It is a floor. Work done with an agent and not marked is invisible.
• Every account that opened a pull request in July to September 2026 opened at least one marked one (7 of 7).
• Issues with the attribution line: 0, 0, 0, 3, 0, 24, 66 by quarter; 66 of 172 (38%) in July to September 2026.

What it does not show. The bars are not higher than before. 171 is level with the busiest quarter in the record (170 in October to December 2022), and January to June 2025 (150, 147) was nearly as busy with almost no marks. Do not say "record" or "doubled".

More pull requests, fewer releases

The slide’s own content sits here. The visual is 560 × 300, bottom right.
<none yet> DRAFT, 2026-10-07. Candidate B: the hypothesis, tested. Every word on the visual is draft wording.

April to September 2026 against April to September 2025, all 25 repositories, bots left out. April is where the AI marks step up (candidate A), so it is the window "since adoption".
• Pull requests opened: 241 → 338 (+40%)
• Pull requests merged: 220 → 280 (+27%)
• Issues opened: 314 → 371 (+18%)
• Issues closed: 285 → 270 (−5%)
• Releases: 41 → 33 (−20%)

The unflattering cuts, to keep beside it
• January to March, before the step: pull requests opened 150 → 144 (−4%); pull requests merged 132 → 119 (−10%); issues opened 165 → 214 (+30%); issues closed 137 → 193 (+41%); releases 17 → 14 (−18%).
• July to September 2025 was a weak quarter (94 pull requests opened, against 150 and 147 in the two before it). Much of the rise is 2026 not repeating that dip.
• January to September: pull requests opened 391 → 482 (+23%), issues opened 479 → 585 (+22%), releases 58 → 47 (−19%).
• Only repositories worked on in both years (8 of them), April to September: pull requests opened 162 → 219 (+35%), merged 146 → 176 (+21%), issues opened 165 → 250 (+52%), issues closed 136 → 161 (+18%), releases 29 → 26 (−10%).
• Leaving out repositories new in 2026, April to September: pull requests opened 241 → 290 (+20%), issues opened 314 → 316 (+1%), issues closed 285 → 228 (−20%), releases 41 → 29 (−29%).
• Releases are down in every repository set but one, and issues closed did not rise with issues opened.
