{{ content }} R/Pharma 2026 · Keynote · October Building open-source clinical trial tools with agentic AI Prepared in the open — follow the developer diary → {%- comment -%} One timeline of posts and package releases (_data/releases.yml), grouped by month. Liquid cannot sort a mixed array of posts and data rows, so each item is reduced to a sortable key, "YYYY-MM-DD|kind|rindex": kind is p (post) or r (release) and rindex counts from the end of the source list, so that after the descending sort newer entries sort first within a day. The keys are sorted, grouped by their first seven characters (the month), and each is decoded back to its post or release when rendered. Each month gets a wf-hue-N class (N = position mod 7) that colours its hex marker; the same index is used in the "By month" rail so the two stay in step.
