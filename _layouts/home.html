{{ content }} R/Pharma 2026 · Keynote · October Building open-source clinical trial tools with agentic AI Prepared in the open — follow the developer diary → {%- comment -%} One timeline of posts, quick hits (_links/) and package releases (_data/releases.yml), grouped by month. Liquid cannot sort a mixed array of posts, documents and data rows, so each item is reduced to a sortable key, "YYYY-MM-DD|kind|index": kind is p (post), l (link) or r (release), and the index is chosen so that after the descending sort newer entries sort first within a day (posts and releases are listed newest first, so they count from the end; links are listed oldest first, so they count from the start). The keys are sorted, grouped by their first seven characters (the month), and each is decoded back to its post or release when rendered. Each month gets a wf-hue-N class (N = position mod 7) that colours its hex marker; the same index is used in the "By month" rail so the two stay in step.
