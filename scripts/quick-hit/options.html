Quick hit settings

The extension publishes by committing one file to the blog repository. It needs a GitHub fine-grained token that can write to that repository and nothing else:

  1. Open GitHub → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → the blog repository.
  3. Permissions → Repository → Contents: Read and write. Nothing else.
  4. Paste the token below and save.

The token stays in this browser's extension storage. It is not synced to your other machines.

The "Add to" button needs a small helper on this Mac that lets Chrome reach Reminders. Install it once from the blog checkout with sh scripts/quick-hit/native/install.sh, then allow Chrome to control Reminders when macOS asks.

Shortcuts: ⌥⇧L opens the popup (change it at chrome://extensions/shortcuts); in the popup, ⌘↵ publishes and ⌘⇧↵ adds to the Reminders list.
